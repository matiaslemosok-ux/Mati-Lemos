# Portfolio - Matías Lemos

## Descripción

Este proyecto corresponde a mi portfolio personal desarrollado como parte del curso de Desarrollo Web.

El sitio fue construido utilizando HTML5, CSS3, Sass y Bootstrap, aplicando una estructura modular de estilos y un diseño responsive.

También incorpora la librería AOS (Animate On Scroll) para generar animaciones durante el desplazamiento de la página.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass
- Bootstrap 5
- AOS (Animate On Scroll)

---

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/matiaslemosok-ux/Mati-Lemos.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Mati-Lemos
```

---

## Compilar Sass

Instalar Sass (si no está instalado):

```bash
npm install -g sass
```

Compilar automáticamente los archivos Sass:

```bash
sass --watch scss:css
```

Este comando observa todos los archivos dentro de la carpeta `scss` y genera automáticamente el archivo `style.css` dentro de la carpeta `css` cada vez que se realiza un cambio.

---

## Ejecutar el proyecto

Abrir el archivo `index.html` en el navegador o utilizar la extensión **Live Server** de Visual Studio Code para una mejor experiencia durante el desarrollo.
